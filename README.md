# The Path of the Ahl al-Bayt

The true history of Islam through the Ahl al-Bayt: 46 clear stories, 12 proofs, the battles of Imam Ali, lessons from each of the Fourteen from the Feast of the Clan to the Major Occultation, a timeline, the Fourteen Ma'sumin, what each caliph did to the Prophet's family, companions who stood firm, and key dates.

- Stories follow Shia sources and name the Sunni sources that agree (including Sahih al-Bukhari and Sahih Muslim), with a note wherever accounts differ.
- Photos of the shrines and holy places load live from Wikipedia / Wikimedia Commons (free licences, credited on the page). No faces of the Prophet or the Imams are shown.
- Reading progress is saved in the browser.

Plain HTML, CSS and JavaScript — no build step. Content lives in `js/data.js`.
